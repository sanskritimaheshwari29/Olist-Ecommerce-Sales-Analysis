# Olist E-Commerce Sales Analysis 📊

## 📌 Project Overview

This project analyzes Olist e-commerce sales data using **SQL and Power BI** to understand overall business performance, revenue trends, customer behavior, seller performance, payment methods, delivery performance, and sales across different states.

## 🎯 Objective

The main objective of this project is to use **SQL queries for data analysis** and present the results through an interactive **Power BI dashboard** to generate meaningful business insights.

## 🛠️ Tools & Technologies

- MySQL
- SQL
- Power BI
- Power BI Desktop

## 📊 Dashboard Components

The Power BI dashboard includes:

- 💰 Total Revenue
- 🏪 Total Sellers
- 💵 Average Order Value
- 👥 Total Customers
- 🛒 Total Orders
- ⭐ Average Review Score
- 🚚 Average Delivery Time
- 👤 Top Customers
- 📈 Total Revenue by Month
- 📦 Delivery Analysis
- 💳 Payment Method Distribution
- 🛍️ Revenue by Category
- 🏆 Top 10 Sellers by Revenue
- 🗺️ Revenue by State

## 🔎 Interactive Filters

The dashboard provides filters for:

- Date Range
- Customer State
- Product Category
- Payment Type
- Order Status

## 🗄️ SQL Analysis

SQL queries were used to perform calculations and generate analysis such as:

- Total orders
- Total customers
- Total sellers
- Total products
- Total revenue
- Revenue by product category
- Top sellers by revenue
- Customer order analysis
- Delivery performance
- Other business performance metrics

SQL joins were also used to combine data from different Olist tables for analysis.

## 📈 Key Insights

- Total revenue is approximately **R$16.01 million**.
- Total orders are approximately **99.44K**.
- Total customers are approximately **96.10K**.
- Total sellers are approximately **3.095K**.
- Average order value is approximately **R$160.99**.
- Average review score is approximately **4.03**.
- Average delivery time is approximately **12.5 days**.
- **Beauty & Health (beleza_saude)** is the highest-revenue product category.
- **Credit Card** is the most preferred payment method.
- **São Paulo (SP)** contributes the highest sales and revenue among the states.

## 💡 Business Recommendations

- Focus on high-revenue product categories to increase sales.
- Strengthen relationships with top-performing sellers.
- Improve delivery efficiency to enhance customer satisfaction.
- Encourage digital payment methods and installment options.
- Focus on retaining repeat customers through better customer engagement.
- Monitor customer reviews and feedback to improve service quality.
