# Olist E-Commerce Sales Analysis 📊

## 📌 Project Overview

This project analyzes Olist e-commerce sales data using **MySQL and Power BI** to understand sales performance, customer behavior, product categories, payment methods, sellers, and delivery performance.

## 🎯 Objective

The main objective of this project is to use **SQL queries for data analysis** and create an interactive **Power BI dashboard** to generate meaningful business insights.

## 🛠️ Tools & Technologies

- MySQL
- SQL
- Power BI
- Power BI Desktop

## 📊 Dashboard Highlights

The Power BI dashboard includes:

- 💰 Total Revenue
- 🛒 Total Orders
- 👥 Total Customers
- 🏪 Total Sellers
- 💳 Payment Method Distribution
- 📦 Revenue by Product Category
- 📈 Monthly Revenue Trends
- ⭐ Average Review Score
- 🚚 Average Delivery Time
- 🏆 Top Customers
- 🏆 Top Sellers
- 🗺️ Revenue by State

## 🔍 Key Insights

- Total revenue generated: **R$16.01 million**
- Total orders: **99.44K**
- Total customers: **96.10K**
- Total sellers: **3.095K**
- Average order value: **R$160.99**
- Average review score: **4.03**
- Average delivery time: **12.5 days**
- **Beauty & Health** is the highest-revenue product category.
- **Credit Card** is the most preferred payment method.
- São Paulo contributes the highest sales and revenue among the states.

## 🗄️ SQL Analysis

SQL queries were used to calculate and analyze:

- Total orders
- Total customers
- Total sellers
- Total products
- Total revenue
- Revenue by product category
- Top sellers
- Customer order analysis
- Delivery performance
- Other business metrics

## 📈 Power BI Dashboard

The SQL analysis was used along with the Olist dataset to build an interactive Power BI dashboard with filters for:

- Date Range
- Customer State
- Product Category
- Payment Type
- Order Status

## 💡 Business Recommendations

- Promote high-performing product categories.
- Improve delivery speed in remote regions.
- Strengthen relationships with top-performing sellers.
- Encourage credit-card and installment payments.
- Focus on retaining repeat customers.
- Monitor customer reviews to improve satisfaction.
